A top-down stealth game for the [make.fun best stealth game bounty](https://make.fun/bounty/best-stealth-game-20261121-1759). Sneak past patrolling guards, use cover to stay out of their vision cones, and reach the exit unseen. Played with keyboard and mouse in a desktop browser; static files only, no network requests.

Play it: serve `game/` with any static HTTP server and open `game/index.html`.
